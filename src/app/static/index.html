Limitations

    
    
      
  • Labels were generated automatically (similarity rule and AI first-pass review); a person has not verified any of them yet.
    • 
      
  • On 62 unseen projects, main 40 reached Average Precision 0.0160 against a random baseline of 0.0080. Comparison 42 reached 0.0442, but 5 of its 6 true positives came from one project.
    • 
      
  • Scores are uncalibrated: compare methods within a file; do not read a score as a probability.
    • 
      
  • Badges use a user-chosen 0.70 review cutoff, which is not validated: on development data it flags about 11% of methods and finds about 20% of renames, so most flagged methods will not be renamed.
    • 
      
  • The validated Stage 8 threshold (main 0.859, comparison 0.846) is shown in the method details; it transferred imperfectly to the refitted model.
    • 
      
  • One file at a time. Trained on files developers changed in ActRef commits from 323 projects; other code bases may differ.
